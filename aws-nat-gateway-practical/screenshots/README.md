# AWS Console screenshots

This folder is intentionally provided for **your own real console screenshots**.

The AWS console is account-, Region-, and feature-rollout-dependent. To avoid misleading students with fabricated or stale UI images, this repository uses original architecture diagrams and tells you exactly which live console screens to capture.

Capture the screenshots listed in the main README and save them here using the exact filenames. Hide account IDs, usernames, ARNs, and sensitive IP details before committing publicly.
